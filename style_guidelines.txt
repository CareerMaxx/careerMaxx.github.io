CareerMaxx - Website Syle Guidelines
SEG 2900 - Gr 17


1.Overall Design
- White background, purple and lavender palette with special layout components
- Simplistic, modern design using white space and rounded corners
- Subtle hover animations on cards and buttons
- Every single page uses the same navbar, sign-up pop-up and button banner

5. Buttons 

    Base button (always include) :    .button
        Dark button :                     .button-dark

7. Hover Animations

    Feature cards :     lift 5px  (transform: translateY(-5px), 0.3s ease)
    Pricing cards :     lift 10px + shadow (0 15px 30px rgba(0, 0, 0, 0.12))
    Dark buttons :      background turns purple
    Pricing buttons :   background turns #33354a
    Nav links :         text turns purple

    New hover effects should use transition: 0.3s ease to match.

8. Responsive Design

    Two breakpoints are used. Add your page's mobile rules inside these, not new ones.

    Tablet (max-width: 900px)
        - Hero stacks vertically
        - Feature cards stack vertically
        - Team cards wrap (minimum 200px each)
        - Pricing cards stack vertically
        - h1 shrinks to 43px
        - Navbar and links wrap

    Phone (max-width: 500px)
        - Container side padding shrinks to 18px
        - Navbar stacks vertically
        - h1 shrinks to 36px
        - Score ring stacks above its text
        - Team cards take full width

    Always check your page at phone width before pushing.


9. Writing Style

    - Spell "résumé" with accents everywhere
    - Use sentence case for headings and buttons ("Get started", not "Get Started")
    - h1 and h2 headings end with a period ("Three simple steps.")
    - h3 card titles have no period
    - Tags and small labels are ALL CAPS
    - Main call-to-action buttons end with an arrow: "Get started →"
    - Keep text short and friendly, written for students


10. Code Organization
    - Multiple static HTML pages share one style.css and one script.js
    - Images go in the UI-Images/ folder
    - style.css starts with the :root variables, then sections in this order:
      Basic Setup, Navigation Bar, Buttons, Hero, Score Panel, Section Headings,
      Features, Pastel Icons, Team Page, Bottom Banner, Popup, Responsive, Pricing
    - Section titles in CSS use this format:
      /* ---------- Section Name ---------- */
    - HTML comments mark each section: <!-- Navigation Bar -->
    - Class names are lowercase with hyphens (e.g. .score-card)
    - Indent with 4 spaces
11. JavaScript and Accessibility Extras

    >>> script.js <<<
        Close popup with Escape :    keydown listener on document
        Form validation :            message shown in .form-message if the password has fewer than 8 characters
        Success message :            "Thank you! Your account has been created." and the form is reset
        Back to top button :         created by script.js (no HTML needed), class .back-to-top
        Shown when :                 the page is scrolled more than 400px (class .visible is added)

        Note: the extras are placed at the top of script.js, before the original popup code,
        so they still work on a page that has no popup.

    >>> CSS extras (end of style.css) <<<
        Smooth scrolling :           html { scroll-behavior: smooth; }
        Keyboard focus outline :     a, button, input :focus-visible (3px purple outline)
        Form message (gray text) :   .form-message
        Back to top button :         .back-to-top, .back-to-top.visible
        Back to top on hover :       background turns purple (same as dark buttons)
