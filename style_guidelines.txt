6. Layout and Cards

Summary: 
    * Page containers like .countainer or .feature wrap content and make it look nice 
    * Flex helpers like .row-container and .column-container organize your content
    * Border radius is Small: 10px, Medium: 16px-22px or Large: 28-30px with 1px solids


    (Please follow the layout so that each page is consistent)

    >>> Containers <<<
        Normal container:   .container
        Veritcal container: .row-container
        Horizontal container: .column-container

    >>> Section headings <<<
        Section heading .section-heading or .section-heading .tag
        Header 2 section heading: .section-heading h2 
        Section heading (gray); .section-heading p

    >>> Features container <<<
        Features container :    .features
        Singular feature box:   .feature
        Feature hover animation: .feature-hover
        Feature with smaller text: .feature h3
        Feautre (gray) .feature p 

    >>> Apearing overlays (Sign up Pop-up) <<<
        Overlay that apears over page : .overlay, .overlay-show 
        "Modal" layout classes : modal, modal h2, modal input, modal button
        Closing it (button) : .close

    >>> Icons <<<
        Icon format class : .icon
        Icon colors (check colors previous color section) .<<color>>-icon


    >> Score card layouts <<<
        Normal score card : .score-card
        With header 2 : .score-card h2
        Description : .card-description
        Score circle icon : .ring-row, .ring, .ring-inner, ring-text b, .ring p

    >>> Team page layout component <<<
        Team grid container : .team-grid
        Each member card : .team-card
        Team card header 3 .team-card h3
        Team card (gray) .team-card p
        Avatar / icons for each team card : .avatar
        Card footer / bottom : .card-footer

    >>> Pricing page layout components <<<

        Pricing card container: row-container-bottom
        Same styling (all 3 cards): .free-card, Plus-card, Extra-card
        Cards hover animation : .free-card:hover, Plus-card:hover, Extra-card:hover
        Price card : .hero-cards, -herocards, .hero-left 
        Subtitle in cards : .subtitle-pricing .subtitle-pricing p 

        For each card, after the class, add:
            h1 for big text
            p for normal text
            ul for the style/list
            .button to start free trial
            .button-hover for the button hover animation


    >>> Bottom banner <<<
    (Everyone already has these)
    .bottom-banner , bottom-banner h3, bottom-banner p
